# FinanceTracker — macOS App v4.3

Нативное SwiftUI-приложение для Apple Silicon / macOS 26.

## Новое в v4

- отдельный раздел **«Нерегулярные расходы»**;
- обзор без перелистывания месяцев;
- группировка расходов на:
  - разовые;
  - ежеквартальные;
  - ежегодные;
  - произвольные периодические;
- редактирование каждого нерегулярного расхода прямо из этого раздела;
- сводка общей суммы нерегулярных расходов на выбранный год;
- новый тип периодичности **«Один раз»** с конкретными месяцем и годом;
- разовый расход появляется только в заданном месяце/году и больше не повторяется;
- старые записи из `finance.json` остаются совместимыми:
  - 12 месяцев распознаются как ежемесячные;
  - один месяц — как ежегодные;
  - квартальный шаблон — как ежеквартальный.

## Как открыть

Откройте **FinanceTracker.xcodeproj** в Xcode.

Bundle Identifier: `com.local.FinanceTracker`  
Deployment target: macOS 26.0

Данные хранятся отдельно от исходного кода:

`~/Library/Application Support/FinanceTracker/finance.json`

Поэтому обновление файлов проекта не должно удалять введённые в приложение финансовые данные.


## v4.3 — месячные бюджеты по дате баланса

Для расходов есть режим «Бюджет на весь месяц». Его остаток в прогнозе определяется ступенчато:

- 1–7: 100%
- 8–14: 75%
- 15–21: 50%
- 22–28: 25%
- с 29-го: 0%

Начиная с v4.3 уменьшение **не зависит от сегодняшней даты**. Оно привязано к моменту последнего сохранения баланса счёта.

Пример: если баланс был обновлён 9 сентября, продуктовый бюджет учитывается как 75% и останется на 75%, пока баланс не будет обновлён снова. Если следующий баланс сохранить 17 сентября, остаток бюджета станет 50%.

Дата актуальности баланса хранится в `finance.json`, входит в снимки истории и восстанавливается вместе со снимком. Старые файлы данных совместимы: пока после обновления приложения баланс ещё ни разу не сохранён, бюджет текущего/будущего месяца учитывается на 100%.

Кнопка «Добавить доход или расход» находится в верхней части экрана «Обзор».
